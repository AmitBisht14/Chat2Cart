# Instructions for every story

You are implementing one GitHub issue (a user story) in the Chat2Cart repository. The issue follows below.

- Read `CLAUDE.md`, `docs/blueprint.md` and `.claude/rules/` first, then follow `.claude/rules/story.md`.
- Implement only the issue's implementation plan. Keep the scope small and meet every acceptance criterion.
- Never edit `agent/src/chat2cart/swiggy/allowlist.py` unless the issue is P09.
- Never touch real accounts or call blocked Swiggy tools (checkout, payment, order confirmation).
- Run `make check` until it passes.
- Commit with Conventional Commits, ending the message with `Refs #<issue number>`. Do not push.
